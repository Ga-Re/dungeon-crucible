# Dungeon Crucible

Kampagnen-Werkzeug für Dungeons & Dragons: planen, Karten bauen, Kreaturen pflegen und am Tisch leiten.

- **Design-Demo:** `design-demo/index.html` im Browser öffnen (eine Datei, keine Installation)
- **Plan:** [`docs/PLAN.md`](docs/PLAN.md)

`design-demo/demo.html` ist der Seiteninhalt ohne HTML-Gerüst (Quelle für die veröffentlichte Vorschau);
`index.html` ist daraus erzeugt.
